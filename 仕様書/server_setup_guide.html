🔧Step 2：リモートデスクトップ上でデータ用RAID（Array 2）を単体4本にソフトウェア分割
新サーバ 192.168.1.163 RDP上で操作

リモートデスクトップ（mstsc ➔ 192.168.1.163）で新サーバに接続し、Windows上からデータ用アレイだけを4本の単体SSD（Non-RAID Volume）へ切り替えます（OS再起動・BIOS操作は一切不要です）。

① AMD RAIDXpert2 管理ツールの起動（未導入の場合は導入）

  1. スタートメニューに RAIDXpert2 がある場合はそのまま起動します。
  2. まだ入っていない場合は、新サーバのブラウザで AMD 公式ドライバページ（Chipsets ➔ AMD Socket AM5 ➔ X670E ➔ AMD RAID Software）または MSI（PRO X670-P WIFI / MS-7E16）サポートページから AMD RAID Software (RAIDXpert2 Utility) をダウンロードしてインストールし、RAIDXpert2 を開きます。

② Array 2（7,451 GB）のみ削除 ➔ 単体 Volume × 4個 作成

  1. 【厳重確認】 約500GBのOS用アレイ（CT500P3PSSD8 / C:）と約8TBのHDD（WDC WD80EFPX）には絶対に触れないでください。
  2. メニュー Array ➔ Delete を開き、約 7,451 GB（7.45 TB）のデータ用アレイ（Array 2）のみにチェックを入れて削除します。
  3. 続いてメニュー Array ➔ Create を開き、RAID Level で Volume（単体ディスク / Non-RAID） を選択し、空いた 4TB SSD を1本だけ選択して作成（Create） します。
  4. 同じ操作を残りの3本にも繰り返し、約 3,726 GB の単体 Volume を合計4個作成します。

✨ 4個作成すると即座に Windows が新しい単体4TB SSD×4本をプラグ＆プレイ認識します（フォーマットやドライブ文字設定は次の Step 3 スクリプトが全自動で行います）。
